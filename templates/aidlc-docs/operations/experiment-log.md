# Experiment Log

実行した事実を追記する。未実行を成功として記録しない。失敗と再試行も残す。
Run manifest・MLflow から転記する際は、同一 run ID の証跡を参照する。

## Runs

- Date / timezone:
- Status / exit code: planned | running | succeeded | failed | stopped
- Hypothesis / source IDs:
- Command（秘密値を除く） / resolved config:
- Git commit / dirty state / environment / hardware:
- Data version / fingerprint / split ID / seeds:
- Start / finish / duration / cost:
- MLflow URI / run ID:
- Local artifacts / manifest:
- Metric（定義・方向・集約・fold ばらつき）:
- Public / Private LB（該当時、submission ref 付き）:
- Business / slice / runtime results:
- Failure / limitations / checks not run:
- 次の作業:

## 名称と説明

実験は `exp012: カテゴリ列の欠損値を補完` のように ID と具体的な変更内容で呼ぶ。
Hypothesis には対象・操作・期待する変化を、Metric には比較対象と同一評価条件を記録する。
略語は初出で説明し、繰り返し使う名称は [問題設定の用語集](../inception/problem-overview.md#用語と名称) と一致させる。
